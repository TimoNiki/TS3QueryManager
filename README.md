# TS3QueryManager

**TS3QueryManager** — это консольный менеджер на Python для управления TeamSpeak 3 сервером через интерфейс Query. Скрипт позволяет параллельно запускать несколько независимых ботов в разных потоках, массово создавать и удалять каналы, а также переключаться между созданными инстансами ботов в реальном времени.

## Скачивание
в релизах вы можете найти уже готовые файлы для ОС. Требования: Python.
## 📋 Особенности
* 🧵 **Многопоточность**: Основной бот и виртуальные боты работают параллельно в собственных потоках.
* 🚀 **Массовое создание**: Быстрое развертывание заданного количества полупостоянных (Semi-Permanent) каналов.
* 🧹 **Умное удаление**: Поддержка удаления одиночных каналов и массовой очистки по диапазону номеров (например, от `prefix_1` до `prefix_10`).
* 🎮 **Динамическое управление**: Переключение «на лету» между созданным пулом ботов прямо из консоли.

## ⚙️ Требования
Для работы скрипта требуется установленная библиотека `ts3`.

```bash
pip install ts3
```

## 🚀 Использование

1. Запустите скрипт через терминал:
   ```bash
   python TS3QueryBot.py
   ```
2. Задайте параметры авторизации и подключитесь к серверу:
   ```text
   Enter command > set name serveradmin
   Enter command > set password secret_password
   Enter command > connect localhost
   ```

## 💻 Доступные команды

### Настройка и подключение
* `set name [USERNAME]` — установить логин для Query-подключения.
* `set password [PASSWORD]` — установить пароль для Query-подключения.
* `connect [HOST]` — подключиться к серверу (по умолчанию `localhost`, порт `10011`).

### Управление ботами
* `bots add [BOT_NAME] [PRIVILEGE_LEVEL]` — создать нового виртуального бота с указанным именем и уровнем привилегий.
* `bot manage [BOT_NAME]` — переключить консоль на управление конкретным ботом.
* `bot manage exit` — вернуться к управлению главным менеджером (`Main_Bot`).

### Операции с каналами
* `create channel [NAME] [COUNT]` — создать `COUNT` каналов с автонумерацией (Шаблон: `NAME_1`, `NAME_2`...).
* `delete channel [NAME]` — удалить один канал по его точному имени.
* `delete more_channels [START_NAME] to [END_NAME]` — массово удалить каналы в диапазоне номеров (например: `delete more_channels room_1 to room_10`).

### Выход
* `exit` — корректно остановить все потоки ботов и закрыть приложение.
